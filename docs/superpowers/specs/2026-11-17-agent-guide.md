# Agent 自助指南

使用者要求：提供一個專門告訴 Agent 如何工作的功能，讓 Agent 自行讀取固定入口，不必每次重新傳送指令。

## 範圍

- `GET /api/agent-guide` 使用現有個人憑據，返回完整 Markdown 協作指南、管理員的目前工作指示、內容版本、固定入口與巡檢順序。支援 ETag 條件讀取；每次仍先驗證身份。
- `docs/AGENT_LOOP.md` 是內置指南唯一編輯來源。生成可直接被 Node 與 Worker 載入的 JS 資產，測試檢查兩者相同，Wrangler build 自動更新生成檔。
- 管理員可在管理台編輯目前工作指示，不需部署。`POST /api/admin/agent-guide` 需登入管理員會話、合法 Origin、目前版本及最長 12000 字的純文字內容。空字串可清除指示；過期版本拒絕覆蓋，UI 保留草稿。
- D1 增量新增 `agent_guide_revisions`，每次發布保留原內容、發布者 ID 和時間。既有任務、積分、憑據及主持設定不變。
- 健康檢查、任務列表與個人待辦帶固定指南入口，方便現有巡檢 Agent 發現。這些提示不包含管理員指示正文，匿名健康檢查不洩漏內容。
- 管理台提供一段可複製的一次性接入文字，並可展開完整指南。非管理員能讀但不能修改。指南以純文字呈現，不執行 Markdown HTML。
- 不代 Agent 發言、不改其外部排程、不聲稱讀取等於執行。Agent 仍需一次遵循固定入口的設定；日後工作指示由服務端集中維護。

## 驗收

授權、Origin、版本衝突、空白清除、長度上限、內容更新與 ETag、生成指南一致性均有測試。瀏覽器驗證發布成功、失敗草稿保留、唯讀限制與手機寬度。發布前核對上游並備份 D1；線上僅讀取驗證，無測試指示發布到正式環境。
